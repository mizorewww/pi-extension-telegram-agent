# 它能做什么

bot 的能力分两层：所有 bot 都会的基本功，和需要你在配置里逐个打开的工具。bot 只知道自己真正拥有的工具，没开的功能它会如实说做不到。

## 基本功（默认就有）

- **聊天**：被 @、被回复或被叫到名字时一定回应；普通消息按概率偶尔接话，也可以按人格选择不说话。
- **sticker 和 reaction**：从你配置的 sticker 包里挑表情发，或者给某条消息点个 reaction。
- **看懂上下文**：知道谁回复了谁、谁引用了哪句话、哪条消息被编辑过。
- **看图和视频**：需要打开 `media.mode`（见[图片和视频](configuration.md#图片和视频)），默认只看到 `[图片]` 这样的占位。

## 可选工具

| 工具 | 打开后能做什么 | 你可以这样问 |
|---|---|---|
| `search` | 联网搜索、读一个公开网页；长网页会一页一页读完 | “@Mochi 查一下今晚的比赛几点开始” · “帮我看看这个链接讲了什么” |
| `codemode` | 写 JavaScript 脚本做精确计算，批量调用其他工具再筛选结果，检索本群的全部历史消息 | “上周谁提过火锅？” · “算一下 12 期、年化 3.2% 的等额本息每月还多少” |
| `hybrid` 媒体模式 | 平时看图片的文字描述，觉得不够时自己打开原图细看，旧消息里的图也能看 | “#1234 那张截图里的报错是什么？” |
| `sandbox` | 一台自己的 Linux 工作区：Pi 原生 read/write/edit/bash，预装 python、node、ffmpeg、imagemagick，能处理群友发的文件，做好的图片和文件直接发到群里 | “把这个 PDF 第二页转成图片发出来” · “统计一下本周每天的消息数，画个柱状图” |
| `tasks` | 把要几分钟以上的深入搜索、调研交给后台任务，做完后回复发起人 | “调研一下三款入门相机的优缺点，整理成报告” |

几点说明：

- 群里的链接不会被自动打开，只有 bot 自己决定用 `search` 时才会读。
- codemode 脚本跑在没有网络、没有文件系统的沙箱里；脚本里可以调用 `send` 先回一句再接着干活，需要执行命令时靠 `sandbox` 工作区。
- `image()` 给模型看图，公开图片或文件仍由 send 发送。后台任务是 Pi 原生 child conversation，重启后按工具恢复规则继续。
- 工作区每周一 05:00 自动清空，管理员也可以随时 `/box reset`。
- 后台任务开始后，bot 会先在群里告诉你它去做了；进展、需要你补充的问题和最终结果都由 bot 转述，任务本身看不到群聊。

## 关于它自己

bot 知道自己是这个开源项目，源代码在 <https://github.com/mizorewww/pi-extension-telegram-agent>。问它“你是怎么判断要不要插话的？”这类问题时，开了 `sandbox` 的 bot 会把仓库 clone 到工作区里读代码再回答，开了 `search` 的 bot 会去 GitHub 上读；两个都没开时它只会把仓库地址告诉你。

## 群内命令

`/help`、`/status` 所有人都能用；换模型、清上下文、调插话频率、清空工作区、管理后台任务等命令只限管理员，完整列表见[群内命令](operations.md#群内命令)。
